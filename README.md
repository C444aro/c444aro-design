# Carolina Romero — Portafolio y CV

Repositorio del portafolio y CV digital de **Carolina Romero** (*Caro Romero*), diseñadora gráfica con profundización en Diseño y Estrategia de Marca.

El proyecto reúne el sitio web del portafolio (portada y CV), construido en HTML, CSS y JavaScript, junto con el sistema de diseño de la marca **c444aro** y los documentos de arquitectura y diseño. La identidad se apoya en el lema *"Menos es más"*: colores primarios vibrantes sobre beige, patrones textiles mexicanos y un mandala pixelado, con tipografías Mr Eaves Sans OT y Avenir.

El sitio lleva música de fondo que solo se apaga con el botón del header. La música vive en el CV y las carpetas de proyecto se abren dentro de él (visor a pantalla completa), así que al entrar y salir de un proyecto continúa en el mismo segundo, sin cortes ni reinicios. El botón no detiene la canción: le quita el sonido, y al volver a encenderla continúa donde va, sin reiniciarse desde el principio.

## Contenido del proyecto

| Carpeta / archivo | Descripción |
| --- | --- |
| `index.html` | Página del portafolio: portada de bienvenida con fondo azul y, al pulsar "Entrar", el CV completo. |
| `cv.html` | Redirige a `index.html` (mantiene los enlaces anteriores). |
| `design.html` | Página del sistema de diseño. |
| `proyectos/` | Páginas de proyectos (ANA, Core Frost, Jugos Invicto, Kleenex Amoxtli, Labdic, entre otros). Se abren dentro del CV en un visor, para no cortar la música. |
| `assets/` | Imágenes, animaciones, íconos, música y recursos gráficos. |
| `assets/musica/musica.js` | Botón y reproducción de la música de fondo (vive en el CV, continúa al abrir proyectos y solo se apaga con el botón; apagarla no detiene la canción, solo le quita el sonido). |
| `assets/musica/musica-cv.m4a` | Pista de fondo del sitio (AAC 96 kbps, listo para reproducirse desde el primer fragmento). |
| `tipografias/` | Tipografías usadas en el sitio (Avenir, Mr Eaves Sans OT, Borel). |
| `docs/` | Documentos de diseño y arquitectura (Word y PDF). |
| `DESIGN.md` | Sistema de diseño: colores, tipografía, componentes y reglas de marca. |
| `CV.md` | Estructura y contenido del CV en lenguaje natural. |
| `cursor.js` | Cursor del sitio (ícono de la marca con rastro): sigue al puntero con fluidez, se esconde al salir de la ventana y no se duplica al abrir un proyecto. |
| `README.md` | Este documento. |
